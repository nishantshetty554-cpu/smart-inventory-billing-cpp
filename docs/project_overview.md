# Smart Inventory & Billing Management System

## Overview

A C++ based inventory and billing management system developed using Object-Oriented Programming and file handling.

## Features

- Add Product
- Update Product
- Delete Product
- Search Product
- View All Products
- Generate Customer Bill
- GST Calculation
- Stock Management
- Low Stock Detection
- CSV Data Storage

## Technologies Used

- C++
- Object-Oriented Programming
- STL
- File Handling
- Data Structures

## How to Compile

```bash
g++ -std=c++17 -Iinclude src/*.cpp -o inventory_app
